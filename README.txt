HOÀNG IT CENTER — Personal System Toolkit

Cách chạy:
1. Giải nén.
2. Mở index.html bằng Chrome/Edge.
3. Để HTTP latency test hoạt động ổn định hơn, có thể chạy bằng Live Server trong VS Code.

Lưu ý:
- HTML/CSS/JavaScript trong trình duyệt không có quyền trực tiếp bật/tắt Firewall, Defender,
  gỡ phần mềm, đọc Registry/Startup hoặc tắt Windows.
- Các module đó trong bản này là UI demo an toàn.
- Thông tin CPU logical cores, device memory, browser, screen và network chỉ hiện khi trình duyệt hỗ trợ API tương ứng.
